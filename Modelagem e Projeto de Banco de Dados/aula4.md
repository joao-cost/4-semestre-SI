# Conhecendo o Microsoft Server Management Studio (SSMS)
- Ferramenta para gerenciar o SQL Server.

## Database
- Diagrama de Banco de Dados
    - Permite criar o diagrama do banco de dados.
    - Permite criar tabelas, relacionamentos, chaves primárias e estrangeiras.
    - *É o local onde são criadas as tabelas do banco de dados através do diagrama.*
- Tables
    - Permite criar tabelas do banco de dados.
    - Permite criar colunas, chaves primárias e estrangeiras.
    - *É o local onde são criadas as tabelas do banco de dados através do código SQL.*
- (Exibições) Views
    - Permite criar exibições (views) do banco de dados.
    - *É o local onde são criadas as exibições do banco de dados através do código SQL.*
- Recursos Externos
    - Permite criar conexões com outros bancos de dados.
    - *É o local onde são criadas as conexões com outros bancos de dados através do código SQL.*
- Sinônimos
    - Permite criar sinônimos para objetos do banco de dados.
    - *É o local onde são criados os sinônimos para objetos do banco de dados através do código SQL.*
    - *Apelido para tabelas, views, procedures, etc.*
- Programação
    - Permite criar procedimentos armazenados (stored procedures), funções, triggers e tipos definidos pelo usuário.
    - *É o local onde são criados os procedimentos armazenados, funções, triggers e tipos definidos pelo usuário através do código SQL.*
- Repositório de Consulta
    - Permite criar consultas SQL.
    - *É o local onde são criadas as consultas SQL através do código SQL.*
- Service Broker
    - Permite criar filas e serviços para comunicação assíncrona entre bancos de dados.
    - *É o local onde são criadas as filas e serviços para comunicação assíncrona entre bancos de dados através do código SQL.*
- Armazenamento
    - Indices, partições e compressão de dados.
    - *É o local onde são criados os índices, partições e compressão de dados através do código SQL.*
- Segurança
    - Permite criar usuários, funções e permissões de acesso ao banco de dados.
    - *É o local onde são criados os usuários, funções e permissões de acesso ao banco de dados através do código SQL.*

- Alta Disponibilidade Always On
    - Permite configurar a alta disponibilidade do banco de dados.
    - *É o local onde são configuradas as opções de alta disponibilidade do banco de dados através do código SQL.*
